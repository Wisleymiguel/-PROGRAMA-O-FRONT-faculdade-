# Portfólio Pessoal — Wisley Miguel

Projeto desenvolvido como atividade prática da disciplina de **Programação Front-End** da UniCesumar.

---

## Sobre o Projeto

Website responsivo de portfólio pessoal construído com HTML5, CSS3 e JavaScript puro, sem frameworks ou bibliotecas externas.

---

## Páginas

| Página | Descrição |
|--------|-----------|
| `index.html` | Home com apresentação e habilidades |
| `sobre.html` | Trajetória profissional e estatísticas |
| `projetos.html` | Portfólio de projetos com filtro interativo |
| `contato.html` | Formulário de contato com validação |

---

## Requisitos Atendidos

- ✅ Layout responsivo (mobile-first)
- ✅ Menu de navegação com hamburger mobile
- ✅ Formulário com validação via JavaScript
- ✅ Efeito 1: Filtro de projetos por categoria
- ✅ Efeito 2: Animação de entrada via Intersection Observer
- ✅ SEO básico em todas as páginas

---

## Como Executar

Abra o `index.html` no navegador ou use a extensão **Live Server** no VS Code.
